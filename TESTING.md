# Vault 67 — руководство по тестированию

Магазин гик-мерча: React + Vite (SPA) + FastAPI (SQLite) + Telegram-бот.
Прод: **https://vault67.ru** (API на `/api`, админка на `/admin`).

> Секреты здесь **не хранятся**. Пароли/токены/API-ключи лежат в `/opt/vault67/server/.env`
> (права `600`, в git не попадает). Смотри ключи: `ADMIN_EMAIL`, `ADMIN_PASSWORD`,
> `TELEGRAM_BOT_TOKEN`, `ADMIN_TELEGRAM_IDS`, `BOT_API_KEY`, `GEMINI_API_KEY`.

## 3. Сборка и деплой фронта

```bash
cd /opt/vault67
~/.bun/bin/bun install          # зависимости (bun.lock)
~/.bun/bin/bun run lint         # tsc --noEmit, должно быть 0 ошибок
~/.bun/bin/bun run build        # → dist/
# бэкап и выкладка
cd /var/www/vault67 && cp -r dist dist.bak-$(date +%Y%m%d_%H%M%S) && rm -rf dist && cp -r /opt/vault67/dist dist
```
Перед изменениями БД всегда делать бэкап: `cp data/vault67.db data/vault67.db.bak-$(date +%Y%m%d_%H%M%S)`.

## 4. Чек-лист

### A. Публичный сайт / каталог
- [ ] `/` открывается, терминальный boot-экран, деньги/скидки без ошибок.
- [ ] Секция «ГОРЯЧИЙ ЛУТ» не пустая (избранное или фолбэк на новые товары).
- [ ] `/catalog` — сетка товаров, фильтры (категория/франшиза/цена), сортировка.
- [ ] `/search?q=...` — поиск находит реальный товар (напр. `warcraft`).
- [ ] Нет «флеша» демо-товаров (Pip-Boy и т.п.) при пустом каталоге.

### B. Карточка товара (deep-link)
- [ ] Прямой заход`/product/1` сразу показывает товар (без «ОШИБКА 404»).
- [ ] Несуществующий `/product/99999` → корректная 404-страница (не бесконечный спиннер).
- [ ] Переход из каталога → карточка → «В каталог» работает.
- [ ] Количество, кнопка «ДОБАВИТЬ В КОРЗИНУ», хоткей `E`.

### C. Корзина / Stash
- [ ] Добавление/удаление/изменение количества.
- [ ] После апдейта версии хранилища старые демо-позиции в корзине исчезают (миграция persist v3).
- [ ] Итог по рублям/крышкам пересчитывается.

### D. Оформление заказа
- [ ] Все поля адреса по умолчанию **пустые** (нет «Лаки 38», нет фейк-телефона).
- [ ] Кнопка «ЗАПОЛНИТЬ ИЗ ПРОФИЛЯ ROBCO» подставляет данные профиля.
- [ ] Быстрые пресеты сектора применяются.
- [ ] Валидация обязательных полей; кнопка «ПОДТВЕРДИТЬ СДЕЛКУ».
- [ ] Успешный заказ → экран «КАРАВАН ОТПРАВЛЕН», номер `V67-...`, трекинг, трекер.
- [ ] Пост-проверка БД: `order_items.product_id` = числовой id товара (не `null`).

### E. Авторизация / регистрация
- [ ] Регистрация нового жителя (валидный email) → вход и редирект в каталог.
- [ ] Повторная регистрация того же email → **видимый** баннер «ОШИБКА: ...».
- [ ] Невалидный email/пароль → понятная ошибка на экране.
- [ ] Логин `tester@vault67.ru`/`TesterVault67!2026` → JWT в `localStorage` (`vault67.token`).
- [ ] `/profile` под авторизацией показывает «ЛИЧНОЕ ДЕЛО ЖИТЕЛЯ».

### F. Админ-панель (Смотритель)
- [ ] Вход под `overseer@vault67.ru` → `/admin` открывается.
- [ ] Обычный dweller НЕ имеет доступа к `/admin` (редирект).
- [ ] CRUD товаров: создать/редактировать/опубликовать/черновик, статусы, склад, featured.
- [ ] Заказы: список, смена статуса, просмотр позиций.
- [ ] Категории/франшизы: добавление/удаление.

### G. Telegram-бот (только для админов)
- [ ] `/start` от админ-ID → меню «➕ Добавить товар» / «🆔 Мой Telegram ID».
- [ ] Не-админ → «🔒 Доступ только для Смотрителя Убежища».
- [ ] Полный флоу товара: тип → франшиза → название RU → оригинал (skip) → описание (перевод) → цена CNY → вес → размеры (skip) → фото → «✅ Готово» → «🚀 Опубликовать».
- [ ] Итог: товар появляется в каталоге на сайте.
- [ ] Новому тестировщику: добавить его Telegram ID в `ADMIN_TELEGRAM_IDS` в `server/.env` и `systemctl restart vault67-bot`.

### H. Прочее
- [ ] `GET /api/health` → 200; `/docs` доступен (см. ограничения).
- [ ] Редиректы: `www`→основной, `http`→`https` (301).
- [ ] Мобильная вёрстка (375px) — без горизонтального скролла.
- [ ] Консоль браузера чистая (ошибки только от намеренных API-запросов).

## 5. Известные ограничения

- Онлайн-оплата — заглушка (уведомление в Telegram админу, без платёжного шлюза).
- Письма/email/SMS не отправляются.
- `/docs` (Swagger) публично открыт на проде — рекомендуется закрыть.
- Неизвестные SPA-маршруты отдают 200 + `index.html` (soft-404).
- `featured` по умолчанию выключен у товаров; витрина падает на фолбэк (новые товары).
